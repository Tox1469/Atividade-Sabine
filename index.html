SGP, sistema de gestão de prestadores

Equipe 8, 2026. Documentação do 1º bimestre e as entregas do 2º bimestre, com o sistema publicado e funcionando.

Sistema

Abrir o sistema publicado O SGP rodando com banco de dados na nuvem. Na tela de login há um botão para entrar como cada perfil. Todos os dados são fictícios e a senha dos usuários de teste é sgp@2026.

Protótipo

Abrir o protótipo navegável As 18 telas do MVP, nos três perfis. Dá para percorrer o fluxo inteiro, do pedido do cliente até a avaliação do atendimento.
